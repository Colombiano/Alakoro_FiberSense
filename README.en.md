### 🎯 Overview

The **Alakoro FiberSense** is a **full-stack open-source** platform for processing, simulating, and interpreting **distributed fiber-optic sensing (DFOS)** data — DAS, DTS, and DSS — in oil & gas well operations.

> 🎸 **Alakoro** is the sacred instrument of **Ogum**, the Orixá of iron, technology, and innovation. This project unites the ancestral strength of the Alakoro with the precision of distributed fiber-optic sensing.

---

### 🚀 10-Second Install

```bash
# Core (simulation, processing, I/O)
pip install alakoro-fibersense

# Full install: desktop GUI + Machine Learning + Kafka/Avro streaming
pip install alakoro-fibersense[gui,ml,streaming]
```

> **Optional extras:** `[gui]` (PySide6 graphical interface), `[ml]` (PyTorch/torchvision), `[streaming]` (Kafka + Avro). The core does not pull in torch or kafka — install only what you will use.

### ✨ What's New in v2.11.0

- ✅ **Desktop GUI** (`alakoro/gui`) — PySide6 + PyQtGraph: drag-and-drop, undo/redo, 2D heatmap with ROI/colormap, interactive profiles, STFT spectrogram, presets/batch, HTML/PDF reports, persistent log, and i18n
- ✅ **DTS/DAS Parity** — all advanced C++20 processors now support DAS and DTS (`*_d_das` / `*_d_dts`); DSS with basic fallback
- ✅ **C++20 Thermal Processors** (`alakoro_core`) — `thermal_gradient_d`, `geothermal_baseline_correction_d`, `thermal_anomaly_detection_d`, `spatial_median_filter_d`
- ✅ **DTSThermalProcessor** (`alakoro/processing/dts_processor.py`) — complete pipeline for cleaning, geothermal correction, dT/dz gradient, anomaly detection, and thermal front velocity
- ✅ **DTSFeatureExtractor** (`alakoro/ml/features.py`) — statistical, spectral, thermal, and anomaly features for ML on DTS
- ✅ **Advanced Thermal Validation** (`alakoro/validation/signature_validator.py`) — gradient, anomaly, and geothermal baseline checks via C++20
- ✅ **Plugin Architecture for Proprietary Drivers** (`alakoro/io/drivers`) — `BaseVendorDriver`, `VendorDriverRegistry` with discovery via the `alakoro.driver` entry point, fallback to DASCore/Xdas, and example `.exd` driver
- ✅ **Complete Library of Advanced C++20 Processors** (`alakoro_core`) — Butterworth, FFT/PSD, CWT, STA/LTA, Hilbert, TKEO, median/SVD/wavelet denoising, STFT, cross-correlation, coherence, gauge compensation, LMS/RLS, EMD/EEMD, NMF
- ✅ **Machine Learning** (`alakoro/ml`) — CNN, U-Net, regressor; Trainer; metrics; inference API
- ✅ **C++20 Core** (`alakoro_core`) — DASData, DTSData, DSSData with pybind11 and modern metaprogramming
- ✅ **Native DASCore Integration** — compatible `AlakoroPatch`/`AlakoroSpool`; read/write of DASCore formats (dasdae, pickle, tdms, segy, febus, optodas, etc.); hybrid DASCore + C++20 pipeline
- ✅ **Native Xdas Integration** — direct `AlakoroPatch ↔ xdas.DataArray` and `AlakoroSpool ↔ xdas.DataCollection` conversion; NetCDF read/write; hybrid Xdas + C++20 pipeline
- ✅ **Escape Hatches** — NumPy, pandas, xarray, ObsPy
- ✅ **ProdML/WITSML** — basic read/write of Energistics files
- ✅ **Streaming** — directory monitoring, Kafka + Avro with PRODML handshake, and MQTT (basic)
- ✅ **15 Canonical Signatures** (M15) — 6 original + 9 new
- ✅ **LF-DAS / eXDTS** (M1) — high-rate temperature (~2s refresh)
- ✅ **Ontology** (`alakoro/ontology`) — RDF/OWL model + bridge with signatures
- ✅ **Unit Tests** — pytest with 213 passing tests
- ✅ **PyPI** — `pip install alakoro-fibersense`
- ✅ **CI/CD** — GitHub Actions with tests, lint, C++ build, PyPI, and release

### 🧪 Quick Start

```python
from alakoro.simulation import SignatureGenerator, WellGeometry, AcquisitionConfig
from alakoro.processing import LFDASProcessor
from alakoro.validation import SignatureValidator

well = WellGeometry(depth_top=0, depth_bottom=3000, n_channels=3000)
acq = AcquisitionConfig(sampling_rate_hz=1000, trace_interval_s=2.0, duration_s=3600)

gen = SignatureGenerator(well, acq)
jt = gen.generate_joule_thomson(interface_depth=1500.0)

lfdas = LFDASProcessor(cutoff_hz=1.0, refresh_rate_target_s=2.0)
result = lfdas.process(jt['das'], trace_interval_s=2.0)

validator = SignatureValidator(well, acq)
validation = validator.validate_signature(jt, result)
print(f"✅ {validation['passed']}/{validation['total']} passed ({validation['success_rate']:.0f}%)")
```

#### 🌡️ DTS Thermal Processing

```python
import numpy as np
from alakoro.processing import DTSThermalProcessor

# temperature: array (n_times, n_channels) in °C
temperature = np.random.randn(1000, 300) * 0.1 + 20.0

proc = DTSThermalProcessor(
    depth_step_m=1.0,
    surface_temp=20.0,
    geothermal_gradient=0.03,
    spatial_median_window=5,
    anomaly_threshold_sigma=3.0,
    use_cpp_backend=True,
)
result = proc.process(temperature)

print(result['thermal_gradient'].shape)  # (1000, 300)
print(result['anomalies'].sum())         # number of anomalous samples
```

### 🔌 Proprietary Drivers

Alakoro v2.9.0 introduces an architecture of **optional plugins for DFOS/DAS vendor drivers**. The core remains MIT; commercial drivers are distributed in separate packages and registered via the `alakoro.driver` entry point.

```python
from alakoro.io.drivers import read_vendor, list_available_drivers, detect_driver

# List available drivers
print(list_available_drivers())

# Detect the right driver
print(detect_driver("/dados/poco.exd"))

# Read with automatic DASCore/Xdas fallback
patch = read_vendor("/dados/poco.exd")

# Force a specific driver
patch = read_vendor("/dados/poco.bin", vendor_hint="my_vendor")
```

> 📖 See the full guide at [docs/drivers/plugins.md](docs/drivers/plugins.md).

- 🗺️ 2D heatmap with ROI, colormap, and configurable scale
- 📈 Interactive profiles (time selection, mean ± deviation)

- 🌡️ DTS thermal panel: gradient, geothermal baseline, anomalies, complete pipeline

### 📂 Reading Data

```python
# Via DASCore
from alakoro.io.dascore_formats import read as read_dascore
spool = read_dascore("/dados/poco_tdms/")

# Via Xdas
from alakoro.io.xdas_formats import read_xdas
patch = read_xdas("/dados/poco.nc")

# Direct conversion
from alakoro.io.xdas_adapter import alakoro_to_xdas, xdas_to_alakoro
xda = alakoro_to_xdas(patch)
patch_back = xdas_to_alakoro(xda)
```

### 🗜️ Serialization and Streaming

```python
# Avro (Python/fastavro) — ideal for Kafka and data lakes
payload = patch.to_avro_bytes(metadata={"sampling_rate_hz": 1000.0})
restored = AlakoroPatch.from_avro_bytes(payload)

# Protobuf (C++20) — high performance, optional in the build
# pip install -e . --config-settings=cmake.define.ALAKORO_WITH_PROTOBUF=ON
payload = patch.to_protobuf_bytes()
restored = AlakoroPatch.from_protobuf_bytes(payload, modality="das")

# Kafka + Avro + PRODML handshake
from alakoro.io.streaming import KafkaStreamDriver

driver = KafkaStreamDriver("localhost:9092")
with driver:
    driver.connect(profile={"well_id": "W-01", "gauge_length_m": 10.0})
    driver.produce(patch)
```

> 📖 See [docs/api/serialization.md](docs/api/serialization.md) and [docs/integration/kafka_avro.md](docs/integration/kafka_avro.md).
